# MoodMate สำหรับบริษัท เงินดีมีชัย จำกัด

ต้นแบบธีม 2 สำหรับงาน MBA ใช้สาธิตเส้นทางพนักงาน: เช็กอินความรู้สึก → เลือกเพื่อนคุยและวิว → พูดคุยตัวอย่าง → จองจิตแพทย์จำลอง

## เปิดดูในเครื่อง

ดับเบิลคลิกไฟล์ index.html หรืออัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages โดยต้องคงโฟลเดอร์ assets ไว้ข้างไฟล์ index.html

## เผยแพร่ผ่าน GitHub Pages

1. เข้าบัญชี GitHub แล้วเลือก New repository ตั้งชื่อ moodmate-mba และเลือก Public เพื่อใช้ GitHub Pages แบบสาธารณะ
2. เปิดโฟลเดอร์ moodmate-github ที่แตกจาก ZIP แล้วอัปโหลด index.html, README.md และโฟลเดอร์ assets ทั้งโฟลเดอร์ผ่าน Add file → Upload files จากนั้นกด Commit changes ตรวจว่าหน้าแรกของ repo มี index.html อยู่ระดับบนสุด และรูปอยู่ที่ assets/companions.png, assets/scenes.png, assets/doctors.png
3. ไป Settings → Pages → Build and deployment → Source: Deploy from a branch เลือก main และ /(root) กด Save
4. รอระบบแสดงลิงก์ในหน้า Pages แล้วเปิด https://ชื่อบัญชี.github.io/moodmate-mba/ (แทนชื่อบัญชีจริง) ตรวจภาพ 3 มิติ การเลือกวิว หน้าแพทย์ และวันเวลา
5. ถ้าจะแก้เนื้อหา ให้แก้ index.html แล้วอัปโหลดทับ/Commit ใหม่ GitHub Pages จะเผยแพร่เวอร์ชันใหม่อัตโนมัติ

คู่มือ GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## สิ่งที่ทำงานในต้นแบบ

- เลือกระดับความเครียด สัตว์ 9 แบบ และวิว 9 แบบ
- พิมพ์ข้อความและรับคำตอบตัวอย่างที่กำหนดไว้ล่วงหน้า
- กดฟังคำแนะนำผ่านเสียงของเบราว์เซอร์
- เลือกแพทย์สมมติ 3 คนและวันเวลา: วันธรรมดา 10:00, 13:00, 15:30, 18:00, 19:00; วันหยุด 09:00, 10:00, 14:00, 15:00
- แสดงราคาเฉพาะส่วนที่พนักงานจ่าย: เวลาปกติ 900 บาท/40 นาที; หลังเลิกงานและวันหยุด 1,350 บาท/30 นาที
- ปุ่มยืนยันนัดแสดงผลในหน้าเว็บเท่านั้น ไม่มีการรับนัดหรือชำระเงินจริง

## ก่อนเปิดบริการจริง

GitHub Pages เป็นเว็บสาธารณะแบบ static ไม่ใช่ระบบเก็บข้อมูลสุขภาพที่เหมาะสำหรับใช้งานจริง โค้ดนี้ไม่มีการส่งคะแนนความเครียดหรือบทสนทนาไปยัง HR หรือฐานข้อมูล และยังไม่เชื่อม AI, ระบบจองของโรงพยาบาล, การชำระเงิน หรือการรับเสียงพูดเข้าระบบ

ต้องมีข้อตกลงกับโรงพยาบาลและแพทย์จริงก่อนใช้ชื่อ/รูป/ตารางนัดจริง ตรวจทานคลังคำตอบโดยผู้เชี่ยวชาญ จัดระบบสิทธิและความยินยอม แยกข้อมูลสุขภาพจาก HR กำหนดทางส่งต่อกรณีฉุกเฉิน และทดสอบความปลอดภัยก่อนเปิดใช้กับพนักงาน

ภาพแพทย์เป็นบุคคลที่สร้างขึ้นเพื่อสาธิต ไม่ใช่บุคลากรจริงของโรงพยาบาลใด ราคาทั้งหมดเป็นสมมติฐานสำหรับโครงงาน
